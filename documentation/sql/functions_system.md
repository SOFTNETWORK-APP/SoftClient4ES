# System Functions

---

### Function: VERSION
**Description:**  
Not available: `VERSION()` is not a function of this engine, and `SELECT VERSION() AS v` is
rejected by the parser.

**Inputs:** 
- none

**Output:** 
- `VARCHAR`

**Example:**
```sql
-- rejected by the parser
SELECT VERSION() AS v;
```
